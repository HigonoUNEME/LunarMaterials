インタラクティブ講義：4パラメータ半量子的(FPSQ)モデル
概要
本プロジェクトは、4パラメータ半量子的(FPSQ)モデルに関するインタラクティブな講義資料です。固体物理学や材料科学を学ぶ学生、研究者を対象に、光（電磁波）と物質の相互作用を記述する複雑な物理モデルを、視覚的かつ動的なデモンストレーションを通して直感的に理解できるよう設計されています。

主な機能
基礎概念の解説: 誘電関数やフォノンといった、モデルを理解するために不可欠な物理的概念を分かりやすく解説します。

数式の可視化: FPSQモデルの核心となる数式を提示し、各パラメータが持つ物理的な意味を掘り下げます。

インタラクティブ・デモ: スライダーを操作することで、モデルの各パラメータ（TO/LOフォノン周波数、減衰定数）が誘電率の周波数応答にどのような影響を与えるかをリアルタイムで確認できます。これにより、理論と現象が結びつく様子を直接体験できます。

応用例と意義: 論文から引用した具体的な研究例を通じて、このモデルが実際の研究においてどのように活用され、どのような科学的意義を持つのかを解説します。

技術スタック
HTML: アプリケーションの骨格を構築。

CSS (Tailwind CSS): レスポンシブでクリーンなUI/UXを提供。

JavaScript: ユーザーの操作に応じてグラフを動的に更新するコアロジックを実装。

Chart.js: インタラクティブな誘電関数グラフの描画に使用。

MathJax: 複雑な数式をウェブ上で美しく表示。

使い方
ブラウザでinteractive_lecture_fpsq_model.htmlファイルを開くだけで、すぐに利用できます。

ページをスクロールして、各セクションの解説を読み進めてください。

「インタラクティブ・デモ」セクションでは、スライダーを左右に動かしてパラメータの値を変更し、グラフの変化を観察してください。

画面上部のナビゲーションボタンを使えば、各セクションに素早く移動できます。
