# プチ探究 課題ブリーフ：月のデータで「基地の場所」を提案する

対象：プチ探究テーマ1「**人間の地球外居住で発生する問題を調査し、その解決策を提案せよ**」を
選んだグループ。要件定義書 Ver.1.5 §5（層2b）。

このブリーフは「問いの立て方」と「ゴールの形」を示すものです。**何を問うか・どの
データをどう使うか・どこを最適地とするかは、あなたたちが決めます**（探究講座の
「手順どおりに進める解析体験」とは違います）。

---

## 1. この探究のゴール

**月の公開データを根拠に、あなたたちが考える「月面基地の最適地」を提案する。**

ただし「最適」は、基地の**目的**によって変わります。まず、どんな基地をつくりたいかを
自分たちで決めてください。例（これに限らない）：

- ☀️ 太陽光発電を主力にする基地（一年中日が当たる場所がほしい）
- 🧊 水（氷）を採る基地（氷は「永久影」にありそう）
- 🏠 人が長く住む総合基地（電力・温度・氷へのアクセスをバランスさせたい）
- 🔭 天文台（暗くて冷たくて、温度が安定した場所がほしい）
- 📡 地球との通信中継基地（地球が見えて、電力もほしい）

目的が決まったら、「その目的にとって良い場所とは、データのどの値がどうなっている場所か」を
自分たちで定義します。ここが探究の中心です。

---

## 2. 使えるデータ（`moonkit` ヘルパー経由。詳しい使い方は別紙チートシート）

| 呼び出し | 中身 | 主な列 |
|---|---|---|
| `load('クレーター')` | 月全体のクレーター（Robbins DB, 直径8km以上, 36,377個） | `lat, lon, diam_km, eccentricity, ellipticity` |
| `load('クレーター深さ')` | クレーターの直径と深さ（Wang & Wu 2021, 24,982個） | `lat, lon, diameter_km, depth_km, depth_diameter_ratio` |
| `load('クレーター年代')` | クレーターの推定地質年代（DeepCraters, 18,996個） | `Lat, Lon, Diam_km, Age`(1〜5), `Age_name` |
| `load('温度')` | 月全体の温度。地点ごとに現地時間0〜23時のカーブ（Diviner, 259,200地点） | `lat, lon, temp_noon_K, temp_midnight_K, temp_diff_K, t_lt00`〜`t_lt23` |
| `load('極域日照')` | 南極・北極の日照率と永久影率（LOLA, 157,922地点） | `lat, lon, average_illumination_percent, permanent_shadow_fraction` |

**データの注意（提案に必ず書くこと）**
- 温度のカーブが信頼できるのは概ね **緯度 ±70度より低い**範囲。極付近はカーブが平坦・不規則になる。
- 日照率の数字（○○%）は、他の資料の数字と**そのまま比べない**。「暗い／明るい」の順序は信頼できる。
- クレーターの「年代」は5段階の**推定**。細かい年数ではない。

## 3. 進め方の目安（時期は学校のプチ探究の予定に合わせる）

| 時期 | やること |
|---|---|
| **導入** | 生成AI（Gemini 等）も使いながら、このブリーフを踏まえて **自分たちの問い（RQ）** を具体化する。「月面基地の最適地はどこか」ではまだ大きすぎる。基地の目的を決め、「○○基地にとって良い場所を、△△というデータの□□という条件で探す」まで絞る |
| **追究** | データで確かめる。**まず予想を書いてから**分析する。予想と違う結果が出たら、なぜかを考える（そこが一番おもしろい）。1つの指標だけで決めず、複数の見方をする |
| （夏休み） | 追究の続き、発表の準備、わからなかったことの整理 |
| **発信** | 発表（スライドまたはポスター）。助言講師の講評をもらう |

---

## 4. 成果物（発信）に必ず入れる要素

1. **立てた問い（RQ）** … 最初に立てた問いと、途中で変えたなら変えた理由
2. **基地の目的と、「良い場所」の定義** … データのどの値がどうなっていれば良いとしたか
3. **使ったデータと分析** … グラフ・表。予想と結果
4. **提案する場所** … 緯度・経度。なぜそこか（他の候補と比べて）
5. **提案の限界** … データの限界、考えられていない要素、「本当はこういうデータも見たかった」

---

## 5. 問いの種（迷ったときのヒント。正解ではない）

- 温度が一番「安定している」場所はどこ？　それは日が当たる場所と一致する？
- 月の「海」と「陸」で、基地に向いているのはどっち？（着陸のしやすさ、温度、地質年代）
- クレーターの中と外で温度は違う？（`classify_by_box` や `region` で切り出して比べる）
- 永久影の「ふち」（氷の近くで、少し日も当たる場所）を探せる？
- 南極と北極、基地に向いているのはどっち？　なぜ？
- `site_score` で条件に重みをつけたとき、重みを変えると最適地はどれくらい動く？
  「動きにくい（どんな重みでも選ばれる）場所」はある？
