## ステップ1：月の温度は1日でどれくらい変わる？

- **学習目標**：(1) 分散（ばらつき）が「1日の温度のふれ幅」という物理量に対応することを体感する。
  大気がない＝温室効果も熱の運搬もない＝放射だけ、を理解する。**(2) データが信頼できる範囲を
  自分で確かめる**（極では温度カーブが崩れる）。温度はこの後「場所を決める指標」としては使わない。
- **操作**：`my_band` に緯度の範囲を入れて実行。`diurnal_curve` でカーブ、`daily_swing`＋`summary` で数値。
  最後に `my_band=(-90,-80)` も試させる。
- **想定される結果**：赤道（`(-10,10)`）で1日の温度差 `t_swing_K` ≈ **290 K**（＝約290℃）。
  いちばん暑いのは正午すぎ、いちばん寒いのは明け方（4〜5時）。緯度を上げると差は小さくなる。
  南極付近（`(-90,-80)`）ではカーブが平坦・ガタガタで温度差も小さい。
- **生徒のつまずき**：
  - 「分散」と「温度差」が結びつかない → 「カーブが大きく上下する＝ばらつきが大きい＝1日の差が大きい」と言い換える。
  - カーブが左右対称だと思っている → 実際は「朝は急に上がり、夕方以降はゆっくり下がる」。
- **問い返しの例**：
  - 「地球の砂漠は昼夜差20〜30℃。月は290℃。この差はどこから？」
  - 「日没後すぐに氷点下にならず、しばらく暖かいのはなぜ？」（地面が熱を蓄えている＝熱慣性）
  - 「南極付近でカーブが崩れたのはなぜ？　このデータはそこで信じていい？」
- **極の扱い（重要）**：極ではカーブが崩れる。これは①データの限界（現地時間の刻みが粗い）
  ②物理（極では太陽が地平線を回るだけで『昼夜』がない）の両方。**その『昼夜がない』ことが、
  極を熱的に魅力的にしている**。ステップ3からは、極でも信頼できる LOLA の日照データに切り替える。
- **温度の意思決定上の役割**：もし「地球から行きやすい」等の理由で赤道・低緯度に基地を置く案が
  出たら、このステップの 290 K がその**反証**になる（信頼できる緯度帯での温度分析）。

## ステップ2：月の「海」と「陸」で何が違う？

- **学習目標**：群比較（グループに分けて統計量を比べる）。空間的なかたよりが時間的な歴史（新旧）を
  語ること。**分類は「発見の後」に来る**（箱を先に与えない）。
- **操作**：(1) `grid_count` で全球のクレーター密度マップ → 低密度の帯を生徒に探させる。
  (2) `scatter(load('クレーター'),'lon','lat')` で月面画像に重ねる → 低密度帯＝黒い海だと気づかせる。
  (3) `near_maria(load('クレーター'), scale=my_scale)` で**公式の海の座標**（USGS 地名辞典23海）を
  使って数値化 → `value_counts` と `summary_by`、`クレーター年代` の `Age` 平均も比べる。
- **想定される結果**（`my_scale=0.8`）：クレーター密度は陸／海 ≈ **3.9 倍**（海 2,232 個・陸 34,145 個）。
  直径の平均は海 24 km・陸 17 km（海に古い巨大盆地が残るため。件数の差が本筋）。年代インデックス
  平均は海 3.15・陸 2.96（海の方がやや新しい。`my_scale` を下げると差がわずかに開く）。
- **生徒のつまずき**：「海に隕石が落ちなかった」と考える → 落ちた数は同じ。落ちた**後**に
  溶岩でおおわれて古いクレーターが消えた（＝海のほうが若い）。
- **問い返しの例**：
  - 「クレーターが少ない＝新しい、と言えるのはなぜ？」
  - 「`my_scale` を 0.5 にすると差はどうなる？　なぜ？」（中心部ほど溶岩が厚い＝若い）
- **最終ゴールとの接続（板書）**：海は平らで**着陸しやすい**が若い。極域高地は古くてでこぼこだが
  **氷（永久影）がある**。基地はこのトレードオフを抱える → ステップ4・5 で扱う。

## ステップ3：月の南極を細かく見る

- **学習目標**：ヒストグラムから自分でしきい値を決める。しきい値を変えると結果が変わることの体感。
- **操作**：`south_pole` で南極、`hist` で日照率の分布、`my_threshold` を自分で決めて当てはまる地点を数える・地図表示。
- **想定される結果**：日照率は 0〜50% に広く分布（中央値 ≈ 22%）。
  - `my_threshold = 1` → 約 8,700 地点（うち「実は永久影でない」のは 3% だけ＝きびしめで良い線）
  - `my_threshold = 15` → 約 28,000 地点（うち 30% は永久影でない＝ゆるすぎる）
- **生徒のつまずき**：しきい値を大きくすればするほど「良い」と思う → 逆。ゆるいと永久影でない場所が混じる。
- **問い返しの例**：「あなたのしきい値で選んだ場所は、本当に全部『氷がありそう』？　どうやって確かめる？」
  （答え合わせは自由探索ノートブック `explore.ipynb` の永久影ツール、または `permanent_shadow_fraction` 列）
- **注意（生徒に必ず伝える）**：日照率の数字（○○%）は、他の資料の数字とそのまま比べない。
  「暗い／明るい」の順序は信頼できるが絶対値は手法によって変わる。

## ステップ4：あなたのミッションの基地はどこ？

- **学習目標**：複数の指標を 0〜1 に正規化し、重みをつけて1つの判断（スコア）にまとめる。
  同じデータでも重みの置き方で答えが変わることを理解する。
- **操作**：`dist_to_permanent_shadow(south_pole(load('極域日照')))` の行はそのまま（各地点に
  「いちばん近い永久影までの距離 `km_to_shadow`」を付ける）。`want` を自分のミッションのものに
  書き換えて `site_score`。全地点をスコアで色分けした地図も出る。**極域の判断は LOLA の
  データだけで行う**（ステップ1の温度は使わない）。
- **想定される結果（教員用の答え）**：

  | ミッション | `want` | 最適地の目安 | その場所の特徴 |
  |---|---|---|---|
  | ☀️ 太陽光発電基地 | `{'average_illumination_percent': ('高い', 1)}` | 緯度 −86°付近の尾根 | 日照率 ≈ 50%、永久影率 0 |
  | 🧊 氷採掘基地 | `{'permanent_shadow_fraction': ('高い', 1)}` | 極点のすぐ近く（−88〜−90°）の永久影 | 日照率 0、永久影率 1.0 |
  | 🏠 有人基地 | `{'average_illumination_percent':('高い',1), 'km_to_shadow':('低い',1), 'permanent_shadow_fraction':('低い',1)}` | 緯度 −85°付近、日向の尾根で永久影のすぐ隣 | 日照率 ≈ 47%（発電できる）、自分は日向（永久影率 0）、氷まで **2〜4 km** |

  → **有人基地は「いちばん明るい場所」でも「氷の中」でもない。日向にいながら氷のすぐ隣**、という
  トレードオフの答え。実際の月南極基地の考え方（lit ridge adjacent to a PSR）と同じ。
- **生徒のつまずき**：重みの意味がわからない → 「両方 1 なら半々。発電を重く見たいなら日照率を 2 にする」。
- **問い返しの例**：「上位1位と2位は何がちがう？」「重みを変えると1位は動く？　どれくらい動かすと変わる？」
- **書かせるもの**：「ここに基地を建てる」1地点（緯度経度）＋理由を3文以上（どの条件を重く見たか、
  他の候補と比べてなぜここか）。

## 発展ステップ6（任意）：機械が決めた基準と自分の基準を比べる

`notebooks/course_moonbase_ml.ipynb`（`moonkit_ml.py` を使う。Colab は sklearn 標準搭載）。
時間が余った班・希望者向け。必須ではない（要件 Ver.1.5 §4.5・Ver.1.6 §3）。所要 20〜30分。

- **課題**：「日照率」と「緯度」の2つから、その場所が**有人基地に向くか**（＝ステップ4の
  有人基地スコアの上位25%か）を当てる。ラベルは日照率＋`km_to_shadow`＋永久影率の3条件スコア。
- **ねらい**：モデルによって境界の形・正解率が違うこと。加えて、**予測したいものは描ける
  2 つの変数（日照率・緯度）だけでは決まらない**（氷までの距離にも左右される）＝隠れた変数。
- **操作**：セルを実行 → 5モデルの決定境界・正解率・「ルールを説明できるか」が出る。
- **想定される結果**：
  - 5モデルの正解率は **87〜90%**（＝真に減らせない誤差が約 11% ある）。「何も考えず
    『向かない』と答える」で 75%。**ランダムフォレスト・ニューラルネットが単純モデルを
    2〜3 ポイント上回る**（弱い構造を拾う）。
  - 境界の形：ロジスティック＝まっすぐな斜め線／決定木＝階段／k近傍＝ぐにゃぐにゃ＋飛び地／
    ニューラルネット＝なめらか／ランダムフォレスト＝ブロック。
  - 境界のまわりでオレンジと青の点が入り混じる＝2 軸だけでは分けきれない。
  - `複雑さ='高い'`（k近傍 k=1 など）→ 練習正解率が上がりテスト正解率は上がらない＝**過学習**。
- **問い返しの例（まとめの議論）**：
  - 「正解率の順位と、『読めるか』の順位は同じ？　ちがう？」
  - 「正解率が 100% にならないのはなぜ？　あと何が分かれば上がる？」（氷までの距離）
  - 「宇宙飛行士が住む場所を、正解率は少し高いが『理由を言えない』モデルで決めていい？」
