# 助言講師・担当教員用メモ：プチ探究「月データで基地の場所を提案する」

要件定義書 Ver.1.5 §5（層2b）。プチ探究テーマ1「人間の地球外居住で発生する問題を
調査し、その解決策を提案せよ」を選んだグループの伴走用。

## この探究の性格

- **足場は弱い**。データ（5種）と道具（`moonkit`／自由探索ツール）は渡すが、
  問い・「良い場所」の定義・提案は生徒が決める。探究講座（層2a、手順どおり進める解析体験）
  とは目的が違う。
- 根拠：石田（2022）。「自らテーマを決めデータを取得する」経験が「楽しさ」「理解」を
  有意に高める。**ここでの伴走の基本は「答えを教えない・方向を決めない」**。横須賀高校の
  事例でいう「黙って見守る」に近い。
- ただし完全放置ではない。下記の「詰まりやすい点」で、**問い返し**によって前に進める。

## 段階ごとの伴走

### 導入（RQを立てる／生成AIを使う）

- **見るべきこと**：問いが「調べ学習」になっていないか。「月面基地はどこがいいか」で
  止まっていないか（大きすぎる）。基地の目的が具体化しているか。
- **生成AIの使い方**：Gemini 等で RQ の案を出させるのは可。ただし**AIの答えをそのまま
  RQにしない**。「AIはこう言ったが、自分たちのデータで確かめられる形になっているか？」を
  必ず問う。AIが挙げた「最適地」を検証するのも立派な探究（むしろ良い）。
- **問い返しの例**：
  - 「その問いは、5つのデータのどれで、どうやって確かめる？」
  - 「『良い場所』ってどういうこと？　データのどの数字がどうなっていれば良い？」
  - 「AIはそう言うけど、根拠は？　自分たちで確かめられる？」

### 追究（データで確かめる）

- **見るべきこと**：
  - **予想を書いてから**分析しているか（葛藤をつくるため）。
  - 予想と違う結果が出たとき、「なぜ」を考えているか。ここを飛ばして次に行きがち。
  - **1つの指標だけで結論を出していないか**（例：日照率だけで決める）。複数の見方をしているか。
  - データの限界を無視していないか（極域の温度カーブ、日照率の絶対値）。
- **ありがちな行き詰まりと問い返し**：
  | 生徒の状態 | 問い返し |
  |---|---|
  | 分析が「地図を眺める」で止まる | 「数字にすると？　平均は？　海と陸で比べると？」 |
  | 予想が当たって満足して終わる | 「なぜそうなる？　仕組みは？　例外はない？」 |
  | 予想が外れて止まる | 「外れたのはおもしろい。何が予想と違った？　なぜだと思う？」 |
  | `site_score` の重みを適当に決めて終わり | 「重みを変えると答えは動く？　どんな重みでも選ばれる場所はある？」 |
  | 1地点に決めきれない | 「決めきれないのはなぜ？　どの条件がぶつかっている？」 |
  | コード/ツールで詰まる | まず「ヘルパー チートシート」を見せる。それでも詰まれば最小限だけ助ける |
- **技術面**：`moonkit` の使い方はチートシート参照。エラーは日本語で出るものが多い。
  Colab のランタイム切れ（放置で切れる）に注意。

### 夏休み〜発信準備

- 追究の穴（「本当はここも見たかった」）を、無理に埋めず**限界として記録**させる。
  それも成果。
- 発表は「きれいにまとめる」より「何を根拠にどう考えたか」が伝わることを優先。

### 発信（9/27・助言講師の講評）

**評価の観点**（点数化より、この観点でコメントを返す）

| 観点 | 見るところ |
|---|---|
| 問いの質 | 「調べ学習」でなく、データで検証できる形に絞れているか。途中で問いを更新したか |
| データの使い方 | 適切なデータを選べたか。1つの指標に頼らず複数の見方をしたか。グラフ・表で示せたか |
| 提案の根拠 | 提案地を、他の候補と比べて説明できるか。「なぜそこか」が言えるか |
| 予想との対話 | 予想を立て、外れたときに考えたか |
| 限界の自覚 | データの限界・考慮できていない要素を自分で言えるか（ここが弱いと減点でなく、伸びしろとして指摘） |
| 主体性 | AIや教員の答えの再現でなく、自分たちの判断があるか |

**講評で避けること**：正解（「本当はここが最適」）を教えること。この探究に唯一の正解は無い
（目的が変われば最適地が変わる、が学びの核）。

## 想定される生徒の提案と、コメントの方向

- **「南極の明るい尾根（日照率50%付近）」**：太陽光基地としては妥当。
  → 「温度差はどうだった？　人が住むなら？」と次を促す。
- **「永久影の中（氷採掘）」**：妥当。
  → 「そこで作業する電力は？　永久影の"ふち"は考えた？」
- **「赤道近く（着陸しやすい・地球から行きやすい）」**：温度差290Kの問題に気づいているか。
  → 「1日の温度差は？　装置はもつ？」
- **「複数候補を目的別に提案」**：探究として上出来。
  → 「目的によって答えが変わることを、どう見せる？」
- **AIが出した最適地をそのまま**：
  → 「自分たちのデータで確かめた？　AIの根拠は妥当だった？」
