# 指導案（あらあら版・v1）：探究基礎「月データでムーンベースの場所を決めよう」（3コマ）

**この文書の位置づけ**：ひとまずの粗い設計図。細部（時間配分の秒単位の調整・発問の文言・
ワークシートの実物）はこれから詰める。既存の `docs/teacher_guide_course.md`（45分×4コマ＝175分版、
Colab/Excel の `moonkit.py`・`course_moonbase.xlsx` を使うステップ1〜5）を土台にしつつ、
**新しく作った3D入口Webアプリ**（https://higonouneme.github.io/moon-data-lesson/）を
導入・振り返りの軸に据えて3コマ（150分）に圧縮する版。

- 対象：高校1年生・学級全体（SSH「探究基礎」相当）、3〜4人班
- 時間：50分×3コマ＝150分
- ねらい：情報Ⅰ (4) データの収集・整理・分析の一連の型（平均・分散・群比較・閾値・複数条件の
  統合評価）を、「月面基地の最適地を決める」という文脈で体験する。**足場は強め**（ゴールと手順を
  用意した「解析体験」型）。
- 学習指導要領との対応：情報Ⅰ (4)／地学基礎 (2)（既存 README と同じ）

---

## 全体設計の考え方

既存の4コマ版（ステップ1〜5＋任意4b・6）をそのまま3コマに詰め込むのは無理があるため、
**役割分担で圧縮する**：

- **3D入口Webアプリ**（今回作ったもの）＝ **「地図感覚をつかむ」担当**。緯度経度・データ層
  （1日の温度／傾斜／地質年代／標高など）・クリックでピンを立てて数値を見る、という
  “いじって慣れる” 体験に特化させ、コマ1の導入と、コマ3での最終確認に使う。
  **統計量の計算やスコア設計はこのアプリではやらない**（そこは表計算／ノートブック側の役割）。
- **`course/course_moonbase.xlsx`（表計算版）または `notebooks/course_moonbase.ipynb`（Colab版）**
  ＝ **「データ分析の型を身につける」担当**。既存ステップ1〜5の中身を使うが、**4b（南極細見）と
  発展6（機械学習）は今回は扱わない**（時間の都合。任意課題として残す）。
- ワークシートは既存 `docs/worksheet_course.pdf` をベースに150分版へ差し替えが必要
  （**未着手・要作成**）。

どちらの教材を使うかは学校のICT環境（Chromebook＋Colabが引けるか、Excelで表計算をするか）で
決まる想定。以下の指導案は教材を問わず共通の流れにし、コマ2・3の「操作」欄だけ両対応で書く。

## 各コマの詳細

### 第1コマ：導入＋3Dアプリで自由探索

- **学習目標**：(1) 月が地球と全く違う環境（大気なし）であることを実感する。(2) 緯度経度・
  データ層という「地図の読み方」に慣れる。(3) 自分の班のミッションに引きつけて場所を予想する
  （＝仮説を立てる）。
- **使う教材**：3D入口Webアプリのみ（https://higonouneme.github.io/moon-data-lesson/）。
  ログイン・インストール不要、教室のPCで各自 or 班で1台開かせる。
- **操作の流れ**（生徒向け簡易手順、ワークシートに載せる想定）：
  1. ドラッグで月を回してみる。表側・裏側があることを確認。
  2. 右上のデータ層メニューで「1日の温度」「全球の傾斜」「地質年代」「標高」を順に見比べる。
  3. 気になった場所をクリックしてピンを立てる。緯度経度とその場所のデータ値をメモ。
  4. 左下の展開図で、自分が今どこを見ているか（水色の範囲）とピンの場所を確認する。
- **問い返しの例**：「月には昼と夜で温度がどれくらい違いそう？」「平らな場所と急な場所、どこで違いが大きい？」「海（暗い部分）と陸（明るい部分）、どちらが新しそう？」
- **教員の留意点**：この時間は**正解を出させない**。数値の正しさより「触って気づく」ことが目的。
  次回以降の「型」につなげる問いだけ置いておく。

### 第2コマ・第3コマ

既存 `docs/teacher_guide_course.md` のステップ1〜4の内容をそのまま使い、**時間を切り詰める**
（各ステップの「予想を書く→実行→記録→議論」のサイクルを短縮し、机間指導での声かけを減らす）。
想定される結果・生徒のつまずき・問い返しの例は同ドキュメントを参照。

第3コマ後半（ステップ4相当）で、**決めた最適地を3D入口Webアプリに戻って確認させる**のが
今回の3コマ版の独自ポイント：表計算／ノートブックで出した緯度経度をWebアプリでクリックし、
「本当にそこは平らか」「本当にそこは日照が良さそうか」を目で見て確かめさせる
（データ分析の結果と可視化を往復させることで、数字と実感を結びつける）。
