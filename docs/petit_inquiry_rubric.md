# プチ探究 ルーブリック：月データで基地の場所を提案する

層2b（プチ探究テーマ1）の発信（発表・ポスター）を評価する観点。
高校の探究活動（SSH「探究基礎」相当）のルーブリック項目2「**データや根拠の提示**」に整合させ、
そこに **この教材の主眼＝「データの限界の自覚」** を独立の観点として加えた 4 観点。

- 使い方：点数化より、各観点でどの段階かを見てコメントを返す。
  **C（要改善）は減点でなく「次への課題」として具体的に伝える。**
- 4 観点のうち R2 が附属の項目2に対応。R4 はこの教材が特に重視する観点。
- 想定される生徒の到達例は [`petit_inquiry_exemplars.md`](petit_inquiry_exemplars.md)。

| | S（十分・模範） | A（おおむね達成） | B（一部・あと一歩） | C（これから） |
|---|---|---|---|---|
| **R1 問いの質**<br>データで検証できる形に絞れているか | 「〈目的〉の基地に良い場所を、〈データ〉の〈条件〉で探す」の形。基地の目的と「良い場所」の定義が数値で言える。追究の途中で問いを意味のある形に更新した | 上の形になっており、目的と「良い場所」が言える。更新はしていないか小さい | 目的は決まったが「良い場所」がまだ曖昧（「日当たりが良い」止まりで数値になっていない）。問いが少し大きい | 「月面基地はどこがいいか」で止まっている。調べ学習になっている |
| **R2 データや根拠の提示**<br>（＝附属 項目2） | 目的に合うデータを複数選び、グラフ・表・数値で示した。**1つの指標に頼らず**、複数の見方（例：日照＋傾斜、密度＋地質図）で確かめた。提案地を他の候補と数値で比較した | 適切なデータを使い、グラフ・表で示した。複数の指標を見たが統合の仕方に弱さがある。提案地の比較はある | 1つの指標だけで結論を出した（例：日照率だけ）。グラフはあるが数値の読み取りが浅い。他候補との比較が弱い | データを「眺めた」段階で数値化していない。グラフが無い、または根拠と結論がつながっていない |
| **R3 予想との対話**<br>予想→反証→仮説の修正が回ったか | 分析前に予想を書き、外れたときに前提を疑い、仮説を立て直して**もう一度データで確かめた**。この往復が複数回ある | 予想を書き、外れたときに「なぜ」を考えた。仮説の修正はあるが再検証まで行っていない | 予想は書いたが、外れても「そういうものか」で流した。当たったら満足して止まった | 予想を書いていない。結果だけを並べている |
| **R4 限界の自覚**<br>データの限界・考慮外の要素を自分で言えるか（**この教材の主眼**） | データの限界を**3つ以上**、具体的に（例：極域の温度カーブは信じられない／日照率・傾斜の絶対値は他資料と比べない／地球可視性のデータが無い／クレーターの深さは"今の深さ"／円近似の海の割合）。「本当はこういうデータも見たかった」を書いた | 限界を2つ程度、具体的に書いた。考慮外の要素にも触れた | 「データには限界がある」と一般論で書いた。具体が1つ | 限界に触れていない。提案を「正解」として提示している |

## 附属ルーブリックとの対応（担当教員が既存様式で採点する場合）

| 附属 SSH 項目 | この教材での見どころ |
|---|---|
| 1 課題設定 | R1 |
| **2 データや根拠の提示** | **R2**（＋R4 を「根拠の妥当性の吟味」として加点） |
| 3 考察 | R3（予想との往復）＋提案の論理 |
| 4 発表・表現 | 発表の分かりやすさ（本ルーブリックでは扱わない。既存様式で） |
| 5 主体性・協働 | AI や教員の答えの再現でなく自分たちの判断があるか。役割分担 |

## 講評テンプレート（助言講師用）

> RQ は「〈　　　〉基地に良い場所を〈　　　〉で探す」の形に〔なっていた／あと一歩だった〕。
> 根拠として〈使ったデータ〉を〈グラフ／表〉で示せていた。特に〈良かった点〉。
> 一方で、〈R2 か R3 の弱点〉。次は〈具体的な next〉。
> データの限界として〈生徒が挙げた限界〉を書けていた〔／ここが弱い。〈例〉のような限界を書けるとよい〕。
> この探究に唯一の正解は無い（目的が変われば最適地が変わる）ことが、提案から伝わって〔いた／いなかった〕。
